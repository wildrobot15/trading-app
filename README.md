# Prompt Vault (Flutter)

A cross-platform mobile app (Android + iOS) for saving, organizing, searching, and reusing AI prompts.

## Implemented Features

- CRUD for prompts (create/edit/delete/save)
- Categories + tags
- Fast keyword search
- One-tap copy prompt
- Favorites
- Recently used and most used sections
- Usage counter
- Light/Dark mode
- Local offline storage with SQLite
- Export prompts to JSON
- Share prompt via native share sheet (WhatsApp/email if installed)

## Default categories

- Productivity
- Work / Office
- Cybersecurity
- Learning
- Content Creation
- Business Ideas
- Personal Use

## Tech stack

- Flutter
- Provider (state management)
- SQLite via sqflite

## Run

```bash
flutter pub get
flutter run
```
